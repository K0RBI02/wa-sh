# Contributing to wa:sh

Thanks for wanting to help! wa:sh is a small project, so a short issue before a
big pull request saves everyone time.

- **Bugs and ideas:** open an [issue](https://github.com/K0RBI02/wa-sh/issues/new/choose).
- **Code:** see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for setup. Please run
  `flutter analyze` and `flutter test` (and `python -m pytest` for the Home
  Assistant integration) before opening a pull request.
- **Translations:** all app texts live in `lib/l10n.dart` (German and English);
  the integration's texts in `custom_components/wash/translations/`.

Keep the spirit: calm, private (no tracking, no account) and small.
